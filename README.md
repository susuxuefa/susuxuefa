# 苏酥学法

我是苏酥，业余法律爱好者。平时读法律和经济，也写一点东西，放在 [susujuris.cn](https://susujuris.cn)。

开始写，是因为很多争论其实卡在概念没说清，或者把「应该怎样」和「实际怎样」混在一起。我想把这些问题拆开，用经济学的工具看法律规则，也用法律去问经济学模型漏了什么。

## 在做的

- **写**：法经济学入门的长文，以及一些回应和反思，收在[文章页](https://susujuris.cn/articles.html)。
- **整理**：逐条核对最高人民法院的司法解释，留下现行有效的 259 条；指导性案例 279 篇，其中 6 篇「不再参照」的做了标注。入口在[司法文件](https://susujuris.cn/documents.html)。
- **开放数据**：元数据和全文放在 [law-data](https://github.com/susuxuefa/law-data)，CC BY 4.0。

## 写作上守的几条

只写有把握的；不编法条编号、判例号、年份和数字；不用空话凑字数。
