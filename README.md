# 苏酥学法

我是苏酥，一个业余法律爱好者。

白天读别的，晚上读法律和经济。读着读着发现，很多被反复争论的问题，其实卡在同一个地方：概念没说清，或者把「应然」和「实然」混在了一起。我写作，主要是为了把这些地方拆开——用经济学的工具看法律规则为什么长这样，也用法律的边界去问经济学模型漏掉了什么。

这个 GitHub 主页和 [susujuris.cn](https://susujuris.cn) 是同一件事的两面：一边是我读到的、想清楚的；一边是我整理出来、别人也能用的。

## 我在做什么

- **写**：法经济学入门的系列长文，从科斯定理、汉德公式讲到效率违约；也写对一些具体问题的回应与反思。文章都收在[文章页](https://susujuris.cn/articles.html)。
- **整理**：把最高人民法院「权威发布」里的司法解释逐条核对，只留现行有效的 259 条；指导性案例 279 篇，其中 6 篇被通知「不再参照」的，如实标注。入口在[司法文件](https://susujuris.cn/documents.html)。
- **做工具**：浏览器里能直接算的小工具，不联网、不留数据，放在站点工具盒里。
- **开放数据**：上面那批整理成果，元数据和全文放在 [law-data](https://github.com/susuxuefa/law-data)，CC BY 4.0，欢迎拿去用、也欢迎指出错误。

## 我怎么写

1. 只写自己有把握的；拿不准就标明不确定，不装作知道。
2. 不编造法条编号、判例号、年份和统计数字——一个数字错了，整篇文章的可信度就没了。
3. 释义不用空话，尽量把「为什么」讲清楚；宁可短，不凑字数。
4. 不追热点。写下来的东西，希望三年后自己还愿意承认。

## 为什么做数据

一开始只是想给自己查「这条解释还有效吗」。后来发现，网上流传的很多版本早就被修改或废止了，却还在被引用。于是就有了那个库：不只收全文，还标出**效力状态**和官方原文链接。它不是官方文本，只是一份认真核对过的整理；发现错漏，请直接开 issue。
