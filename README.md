# 苏酥学法

我是苏酥，业余法律爱好者。

白天读别的，晚上读法律和经济。读久了发现，很多争论卡在同一个地方：概念没说清，或者把应该怎样和实际怎样混在一起。我写作，多半是想把这些问题拆开，看看规则在解决什么，代价落在谁身上。我不追热点，写下的东西，希望几年后自己还愿意承认。

## 我在做什么

- **写**：法经济学入门的长文，从科斯定理、汉德公式讲到效率违约；也写一些回应和反思。文章都收在[文章页](https://susujuris.cn/articles.html)。
- **整理**：把最高人民法院权威发布里的司法解释逐条核对，只留现行有效的 259 条；指导性案例 279 篇，其中 6 篇不再参照的，如实标注。入口在[司法文件](https://susujuris.cn/documents.html)。
- **做工具**：浏览器里能直接算的小工具，不联网、不留数据，放在站点工具盒里。
- **开放数据**：整理成果的元数据和全文放在 [law-data](https://github.com/susuxuefa/law-data)，CC BY 4.0，欢迎拿去用，也欢迎指出错误。

## 为什么做数据

一开始只是想给自己查这条解释还有效吗。后来发现，网上流传的很多版本早就被修改或废止了，却还在被引用。于是就有了那个库：不只收全文，还标出效力状态和官方原文链接。它不是官方文本，只是一份认真核对过的整理；发现错漏，请直接开 issue。
